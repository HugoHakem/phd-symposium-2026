# Original sponsor logos (not used by the website)

These are the organisations' **original** logos, for light backgrounds. They
are here only for sponsors whose logo the website shows in an **adapted**
version, because the site is dark (e.g. dark lettering turned white).

- The logos the website actually shows are in `static/sponsors/`, in the same
  tier folders and with the same file names.
- In each sponsor's YAML file (`src/content/sponsors/<id>.yaml`), `logo:` is the
  version the website shows and `logoOriginal:` points here. Swap the two paths
  to show the original on the website.
- Use these files for anything on a light background, such as print.

Where each logo came from and what was changed is listed in `docs/logos.md`.
