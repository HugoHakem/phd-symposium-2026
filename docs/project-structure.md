# Project Structure

This document describes every directory and file in the project and explains its role.

## Top-level layout

```
phd-symposium-2026/
├── .github/
│   └── workflows/
│       └── deploy.yml          # GitHub Actions CI/CD → GitHub Pages
├── docs/                       # This documentation folder
├── static/                     # Static assets served as-is (publicDir — see astro.config.mjs)
│   ├── brand/                   # Symposium identity
│   │   ├── logo.svg             # Symposium's own logo (Nav, Footer, QR code centre)
│   │   ├── gear1.svg            # Gear illustration (About)
│   │   ├── gear2.svg            # Gear illustration (Hero, Speakers, Footer)
│   │   ├── gear3.svg            # Gear illustration (accent positions)
│   │   ├── gear-all.svg         # Combined gear composition (Hero, Programme, 404)
│   │   └── embl-white.svg       # White EMBL logo for the dark Nav/Footer
│   ├── favicon.svg
│   ├── og-image.png             # Open Graph share image
│   ├── qrcode/                  # Generated by scripts/generate-qr.mjs
│   ├── speakers/                # Speaker headshots, referenced from speaker frontmatter
│   └── sponsors/                # Sponsor logos (<id>.svg), referenced from sponsor frontmatter
│       ├── sponsors/            #   tier: sponsor
│       ├── prizes/              #   tier: prize
│       ├── support/             #   tier: support (EMBO, EMBL Alumni, EMBL)
│       └── cpp/                 #   EMBL Corporate Partnership Programme
│           ├── corporate-partners/
│           └── associate-partners/
├── scripts/
│   └── generate-qr.mjs         # Generates the registration QR code into static/qrcode/
├── src/
│   ├── content/                # All editable site content (Markdown + YAML)
│   ├── components/             # Reusable Astro UI components
│   ├── layouts/                # Page wrapper templates
│   ├── pages/                  # One file = one URL route
│   ├── content.config.ts       # Content Collection schemas (data validation)
│   └── styles/
│       └── global.css          # Global styles, Tailwind theme, utilities
├── astro.config.mjs            # Astro + Tailwind configuration
├── package.json
├── pnpm-lock.yaml
└── tsconfig.json
```

`public/` and `dist/` may also appear locally — both are gitignored build
output (an old default-`publicDir` artifact and the build output
respectively), not source. Edit `static/`, never `public/`.

## `src/content/` — Editable Content

This is where **all site data lives**. You never need to touch a component or page
file to update speakers, the schedule, or sponsors. See [Content Guide](./content-guide.md)
for step-by-step update instructions.

### `src/content.config.ts`
Defines the **schema** (required fields and their types) for each content collection.
Astro validates every content file against this schema at build time — if a required
field is missing or has the wrong type, the build will fail with a clear error message.

### `src/content/speakers/`
One `.md` file per invited speaker. Frontmatter holds structured data; the body is
the speaker's biography rendered as HTML on the Speakers page.

```
speakers/
├── jennifer-roth.md               # Day 1, keynote
├── petra-dittrich.md              # Day 1, talk
├── sarela-garcia-santamarina.md   # Day 1, talk
├── paul-flicek.md                 # Day 1, keynote
├── kerstin-howe.md                # Day 1, talk
├── robert-waterhouse.md           # Day 1, talk
├── virginie-uhlmann.md            # Day 2, talk
├── gaurav-ahuja.md                # Day 2, talk
├── chris-bakan.md                 # Day 2, talk — TBA placeholder, awaiting bio/photo
├── norbert-kraut.md               # Day 2, talk
├── giovanni-stracquadanio.md      # Day 3, talk
└── ross-king.md                   # Day 3, talk
```

The filename (without `.md`) becomes the URL anchor on the Speakers page
(e.g., `jennifer-roth.md` → `/speakers#jennifer-roth`) and the `speakerSlug`
value used to link a schedule session to that speaker.

### `src/content/schedule/`
One `.yaml` file per symposium day. Contains all sessions for that day as a structured
list. The schedule is displayed in order of the `time` field.

```
schedule/
├── day-1.yaml    # Wednesday, December 2, 2026
├── day-2.yaml    # Thursday, December 3, 2026
└── day-3.yaml    # Friday, December 4, 2026
```

### `src/content/sponsors/`
One `.yaml` file per sponsoring organisation (20 as of writing). Files are
grouped visually on the site by their `tier` field (`sponsor`, `prize`, `support`, `grant`, `cpp`),
and `cpp`-tier sponsors are further grouped by `subTier`
(`founder_partner`, `corporate_partner`, `associate_partner`).

```
sponsors/
├── embl.yaml               # tier: support
├── 10x-genomics.yaml       # tier: cpp, subTier: corporate_partner
├── boehringer-ingelheim.yaml
├── illumina.yaml
├── thermofisher.yaml
└── … (20 files total — mostly EMBL Corporate Partnership Programme members)
```

## `src/components/` — UI Components

| File | Purpose |
|------|---------|
| `Nav.astro` | Fixed top navigation bar. Becomes opaque on scroll. Includes mobile hamburger menu and the EMBL logo + symposium logo lockup. Active page link is highlighted automatically via `Astro.url.pathname`. |
| `HeroSection.astro` | Full-viewport hero on the homepage. Includes live JavaScript countdown timer, animated gear background, and CTA buttons. |
| `SpeakerCard.astro` | Reusable card for a single speaker. Displays avatar (or initials placeholder), session type badge, optional keynote badge, name, role/institution, and talk topic. Props: `slug`, `name`, `role`, `institution`, `country`, `topic`, `sessionType`, `day`, `image?`, `compact?`, `keynote?`. |
| `ScheduleDay.astro` | Renders a full day's programme. Receives the parsed YAML data and outputs a colour-coded session list, including an inline keynote badge on sessions with `keynote: true`. The time column is right-aligned for visual scanning. |
| `SponsorsSection.astro` | Groups sponsors by `tier` (`sponsor` / `grant` / `cpp`), with `cpp` further split by `subTier`, and renders them in appropriately-sized grids. |
| `Footer.astro` | Site footer with the EMBL + symposium logo lockup, nav columns, contact links, and a red accent bar. Contains decorative gear backgrounds. |

## `src/layouts/`

### `BaseLayout.astro`
Wraps every page. Handles:
- `<head>` with SEO meta tags (title, description, Open Graph)
- Google Fonts (`<link>` tags for Sora, Spectral, Space Mono)
- Global CSS import
- `<Nav>` at the top, `<Footer>` at the bottom
- A `<slot />` for each page's unique content

Props: `title?`, `description?`, `image?` (all optional, with sensible defaults).

## `src/pages/` — Routes

| File | URL | Description |
|------|-----|-------------|
| `index.astro` | `/` | Homepage: Hero, About/theme section with day-preview cards, Invited speakers band, Key dates, Venue teaser, Sponsors |
| `program.astro` | `/program` | Full 3-day schedule, session-type legend, add-to-calendar links, and registration callout |
| `speakers.astro` | `/speakers` | All speakers in a single unified grid (not grouped by day), each linking down to its full bio panel |
| `about.astro` | `/about` | Symposium history, venue info, travel, accommodation, registration & fees, FAQ, Code of conduct |
| `404.astro` | `/404` | Themed not-found page |
| `calendar.ics.ts` | `/calendar.ics` | Generates a downloadable ICS feed live from the `schedule` content collection — always in sync with the YAML files, no separate calendar data to maintain |

## `src/styles/global.css`

Imports Tailwind CSS and defines the project's design system:

- **`@theme` block** — Custom colour tokens that generate Tailwind utility classes:
  `green-800` (`#0e3535`), `red-600` (`#cb24cb`), `cream`, `parchment`, `ink`, `muted`, etc.
  See `docs/design-system.md` for the full palette.
- **`@layer base`** — Default `font-family`, `background-color`, `color`, and `::selection` styles.
- **`@layer utilities`** — Custom one-off utility classes:
  - `.label-tag` — Small-caps monospace labels
  - `.clip-diagonal-down / -up / -both` — `clip-path` helpers for diagonal section breaks
  - `.text-outline-white / -cyan / -magenta` — Webkit text stroke for outlined headlines
  - `.gear-spin-slow / .gear-spin-reverse` — CSS animation utilities for gear rotation
  - `.fade-up` — CSS animation for staggered entry reveals
- **`@layer components`** — Session-type badge colours (`.badge-keynote`, `.badge-talk`, etc. —
  a validated, fixed-order set, see `docs/design-system.md`) and sponsor tier label colours.
